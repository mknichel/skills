# Research design

Before implementing a project, feature, or task, do some research to ensure that you have the best solution.

If the fix is trivial, like modifying one file or less than 100 lines of code, then this step can be skipped.

## Steps

- Look for similar examples already done in the repository or organization
- Look for past pull requests that have implemented something similar.
- Search on the internet for standard industry approaches for implementing such a solution. Use primary sources (first party docs, open standards, specs, research papers, etc.)
- Search Slack for any mentions related to this project or feature

## Guidelines

- Aim to have 2-3 solutions when possible so that they can be compared and contrasted.
